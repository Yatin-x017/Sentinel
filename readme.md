# Sentinel

Sentinel is an Open-Source Intelligence (OSINT) platform that helps users discover where their personal data may have been leaked or exposed across publicly available sources.

## About

Sentinel brings information from multiple public sources into one platform, allowing users to search for potential data exposure and better understand their digital footprint.

The project is being developed as a college capstone project covering Advanced Programming and Data Engineering.

## Features

* Search for potential data leaks and exposure
* Collect information from multiple public sources
* Analyze and organize collected information
* Monitor relevant public information and news
* Explore location-based public information
* Identify relationships between information from different sources

## Responsible Use

Sentinel is intended for legal and ethical OSINT research.

The project does not aim to:

* Access private or unauthorized information
* Bypass authentication or security controls
* Obtain or distribute stolen credentials
* Facilitate unauthorized access to systems or accounts

Features and functionality may change as development progresses.
